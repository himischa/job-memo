# Job Memo Frontend

React + TypeScript + Vite frontend for Job Memo.

## Setup

```bash
# 1. Copy env file
cp .env.example .env

# 2. Install dependencies
npm install

# 3. Start dev server
npm run dev
```

The app runs at http://localhost:5173.

## Build for production

```bash
npm run build
```

## Lint / Type check

```bash
npx tsc --noEmit
```
